# Security & Zero-Day Disclosure Policy

Security and zero-retention privacy are fundamental pillars of **LawPilot AI**.

---

## 🛡️ Reporting a Vulnerability

If you discover a security vulnerability, memory leak, or authentication bypass in LawPilot AI, please **do NOT report it via a public GitHub issue**.

Instead, please report security issues directly to the author and maintainer **techabbayi**:

* **Security Email**: `srssltd@protonmail.com`

Please include:
1. Detailed description of the issue.
2. Step-by-step reproduction instructions or proof-of-concept payload.
3. Impact assessment on user workspace data.

---

## ⏱️ Response & Disclosure SLA

* **Acknowledgment**: Within 12 hours of receipt.
* **Patch Window**: We request a **90-day private patch window** prior to public disclosure to ensure enterprise self-hosted instances can apply patches safely.
